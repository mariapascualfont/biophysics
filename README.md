# Biophysics 2026-27
Files and submissions for BP (Biophysics) subject of the Bachelor's Degree in Bioinformatics.
## Session 1 
- Exercise 1: Determine the list of pairs of residues whose CA atoms are closer than a given distance
- Exercise 2: Generate a list of all atoms for a given residue number
- Exercise 3: Determine all possible hydrogen bonds (Polar atoms at less than 3.5 Å)
- Exercise 4: Generate a list of all CA atoms of given residue type with coordinates
- Exercise 5: Generate a list of backbone connectivity (i.e. which residues are linked by ordinary peptide bonds)
- Exercise 6: Id 4, but for disulphide bonds
- Exercise 7: Print distances between all atom pairs of two given residues
